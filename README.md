## Загрузочная система x86

- Добавлены загрузочная запись BIOS/MBR и 16-битное ядро x86 для режима
  Legacy BIOS/CSM.
- Реализованы текстовая консоль VGA и клавиатурный ввод; предусмотрен вывод
  через последовательный порт COM1.
- Добавлена сборка raw-образа диска размером 2 ГиБ с одним разделом FAT16.
- Добавлен PowerShell-сценарий `build.ps1` для сборки образа, `run-qemu.ps1`
  для запуска QEMU и `test-qemu.ps1` для интеграционной проверки.
- Исходный код встроенных команд ядра размещён в отдельных ASM-файлах
  каталога `kernel\commands`.

## Командная оболочка и файлы

- Добавлены команды ядра: `HELP`, `CLS`, `VER`, `ECHO`, `DIR`, `TYPE`,
  `WRITE`, `APPEND`, `EDIT`, `DEL`, `RUN`, `REBOOT` и `HALT`.
- Добавлен драйвер FAT16 для корневого каталога и имён формата 8.3:
  перечисление и чтение файлов, создание/перезапись, добавление данных,
  редактирование и удаление.
- Реализована работа с файлами, занимающими несколько кластеров, и запись
  обеих копий FAT.
- Добавлен запуск real-mode программ `.COM` размером до примерно 60 КиБ.
  В образ включены `HELLO.COM` и тестовый много-кластерный файл `MULTI.TXT`.
- Добавлена отдельная оболочка DOS-подобного типа на Python для Windows.
  В ней есть виртуальный диск, пути и несколько дисков, файловые команды,
  переменные окружения и базовая поддержка batch-файлов (`CALL`, `IF`,
  `FOR`, метки и `GOTO`).

## Установка сторонних приложений

- Добавлена установка и удаление отдельных файлов `.COM` в FAT16-образе;
  установленные приложения можно сохранять для включения в следующие сборки.
- Добавлен ZIP-установщик: он устанавливает подходящие по имени 8.3 файлы
  из корня архива, умеет удалять файлы пакета и сохранять исходный ZIP для
  последующих сборок.
- Для PowerShell-установщика `install-app.ps1` добавлены режимы архива,
  удаления, замены и выбора целевого образа (`-Archive`, `-Remove`,
  `-Replace`, `-Image`).
- Установщик проверяет имена и пути в архиве, отбрасывает неподдерживаемые
  файлы и сообщает о пропусках. Каталоги внутри ZIP не импортируются, так как
  ядро пока не поддерживает подкаталоги.
- Проверена обработка ZIP-пакета DOS Navigator: 23 подходящих корневых файла
  устанавливаются, 45 файлов пропускаются. Сам Navigator несовместим с текущим
  подмножеством DOS API и не запускается до рабочего интерфейса.

## Документация и проверка

- `README.md` переведён и дополнен русскими инструкциями по сборке, запуску,
  использованию файловых команд и установке приложений.
- Добавлены модульные тесты Python для оболочки, FAT16 и установщика.
- Подтверждены 15 успешных Python-тестов, интеграционный тест QEMU и отдельная
  проверка установки/удаления ZIP-пакета через PowerShell на тестовом образе.
- Пользователь сообщил, что проверил систему на настоящем ПК и она работает.
  Загрузка на физическом компьютере требует Legacy BIOS/CSM; UEFI-only режим
  не поддерживается.

## Ограничения

- Это не полный MS-DOS: реализовано только подмножество команд и DOS API.
- Поддерживаются FAT16, один диск-образ и корневой каталог; FAT12/FAT32,
  подкаталоги, несколько дисков и загрузка UEFI отсутствуют.
- Формат `.EXE` и программы `.COM`, требующие отсутствующих функций DOS,
  не поддерживаются. Установка файлов стороннего приложения не гарантирует,
  что оно запустится.
- Файлы, созданные внутри гостевой системы, не включаются автоматически
  в следующие сборки образа.
